## 1. Official Project Emblem / Avatar

- **Local Path**: `Assets/icon.png` (and `Documentation/showcase/icon.png`)
- **Dimensions**: 1024 x 1024 pixels (1:1 square aspect ratio)
- **Format**: 32-bit RGBA PNG (lossless)
- **File Size**: ~1.65 MB
- **Color Palette**: Electric Cyan (`#00E5FF`), Dark Slate Neutral (`#141619`), Deep Midnight Blue (`#0B0E14`), Minecraft Dirt/Grass Green.

### Visual Composition
- Modern high-contrast isometric depiction of a stylized 3D printer chassis with glowing cyan edges and an overhead laser print head.
- Inside the print bay, a vibrant translucent blue voxel house hologram is actively being generated.
- On the left side, a floating Minecraft grass block with a curved glowing cyan arrow shows raw materials being fed into the printer.
- On the right side, a corresponding cyan arrow outputs a fully materialized miniature stone-and-wood cottage with warm glowing interior light and chimney smoke.
- Rounded corners optimized for modern square/circular avatar cropping.

### Recommended Usage
- **Modrinth**: Project Icon / Avatar (Dashboard -> Project Details -> Icon).
- **CurseForge**: Project Logo / Avatar (Project Details -> Logo, requires min 400x400).
- **Social Media**: Discord server/bot icon, X/Twitter avatar, GitHub repository social preview.

## 3. In-Game Configuration Screen Showcase

- **Local Path**: `Assets/showcase-config.jpg` (and `Documentation/showcase/showcase-config.jpg`)
- **Dimensions**: 1024 x 571 pixels (16:9 widescreen capture)
- **Format**: 24-bit RGB JPEG
- **File Size**: ~148 KB
- **Color Palette**: UI Dark Neutral (`#141619`), Neon Cyan Frame (`#00E5FF`), Button Slate (`#22272E`), Accent White (`#FFFFFF`).

### Visual Composition
- High-resolution in-game capture of the graphical settings screen (`Keybind: O` or `/shhhprinter config`), designed to match Shhh Builder's dark neutral aesthetic.
- Header displays "Shhh Printer Configuration" with cyan-white dual-tone typography.
- Three organized column containers with glowing cyan borders:

  3. **HUD & Display**: Monitor display icon, `Status HUD: HIDDEN`, `HUD Pos: Top-Right`, and cyan `Done` button.
- Bottom descriptive tooltip card: *"Shhh Printer - Settings: Point your crosshair at ghost blocks to place them automatically."*
